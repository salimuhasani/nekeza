# NEKEZA Android TWA (Trusted Web Activity)

Hii inafunga PWA yako kama APK.

## Build local
1. Weka Android Studio
2. Fungua folder `android-twa`
3. Badilisha host kwenye `app/src/main/res/values/strings.xml`
4. Build → Generate Signed Bundle / APK

## Build GitHub Actions
Actions → **Build APK** → Run workflow → weka URL ya Vercel

## Digital Asset Links (lazima kwa TWA kamili)
Weka faili:
`https://YOUR_DOMAIN/.well-known/assetlinks.json`
(ona route kwenye app.py)
